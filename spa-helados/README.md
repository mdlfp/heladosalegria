Este es el proyecto para la SPA (Single Page App) para el establecimiento local La Mazorquita

## Para empezar

Primer, corre el servidor de desarrollo:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador y mira el resultado.

Este es un establecimiento local en ensenada que ofrece los mejores elotes en la ciudad.
